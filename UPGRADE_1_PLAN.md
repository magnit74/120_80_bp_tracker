# План "Апгрейд 1" (Глобальный Редизайн)

Этот файл фиксирует будущий план глобального обновления дизайна приложения React Native до уровня "10/10" (Apple/Dribbble style).

## Задачи для Апгрейда:
1. **Glassmorphism**: Внедрение библиотеки `expo-blur` для всех карточек и плашек (эффект полупрозрачного матового стекла).
2. **Mesh Gradients**: Замена сплошных белых фонов на анимированные или мягкие градиенты (teal/mint).
3. **Объемные тени**: Кастомные тени `shadowColor: '#0F766E'` с увеличенным радиусом и низкой прозрачностью для свечения.
4. **Микро-анимации**: Внедрение `react-native-reanimated` для пружинистых эффектов при тапе, скролле и появлении.
5. **Градиентный текст**: Внедрение `@react-native-masked-view/masked-view` для переливающихся акцентов (например, показатели давления).
6. **3D-Ассеты**: Использование высококачественных 3D PNG (или Lottie) вместо плоских SVG иконок.
