# История ошибок iOS (White Screen)

1. **Сборка 25 (и ранее)**: Белый экран на iOS. 
   - Удаление `expo-widgets` и `expo-blur` не помогло.
2. **Сборка 26**: Удаление Firebase не помогло.
   - **Установленная причина белого экрана**: В `app.json` оставалась конфигурация `"useFrameworks": "static"` у плагина `expo-build-properties`, добавленная исключительно для поддержки Swift-виджетов. Статическая линковка Pods ломала инициализацию стандартных модулей Expo при старте приложения на iOS.
3. **Сборка 27 (Откат виджетов + Стандартная линковка)**:
   - Полностью вырезан плагин `expo-build-properties` (`useFrameworks: "static"`).
   - Восстановлена стандартная динамическая линковка Expo.
   - Восстановлены базовые Firebase плагины.

4. **Сборка 54 (Codemagic API)**: Ошибка `Failed to install dependencies for pubspec file`.
   - **Причина**: Использование ID графического воркфлоу (Flutter) при вызове API.
   - **Решение**: Запуск воркфлоу `ios-expo-release` напрямую из `codemagic.yaml`.
