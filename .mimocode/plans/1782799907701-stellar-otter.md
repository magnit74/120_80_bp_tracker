## Build Scheme

### Step 1: Prebuild (regenerate android folder)
```bash
cd D:\ANDROID_WORK\PROJECTS\120_80_BP_Treter
npx expo prebuild --platform android --clean
```
Пересоздаст `android/` папку с актуальными настройками.

### Step 2: Set environment variables
```powershell
$env:ANDROID_HOME = "D:\ANDROID_WORK\SDK"
$env:JAVA_HOME = "D:\ANDROID_WORK\AndroidStudio\jbr"
```

### Step 3: Build AAB
```bash
cd D:\ANDROID_WORK\PROJECTS\120_80_BP_Treter\android
.\gradlew.bat bundleRelease
```
Результат будет в: `android\app\build\outputs\bundle\release\app-release.aab`

### Step 4: Copy AAB to KEY GOOGLE PM
```powershell
Copy-Item "android\app\build\outputs\bundle\release\app-release.aab" "120_80_dev_drafts\KEY GOOGLE PM\app-release.aab" -Force
```

### Step 5: Verify
- Проверить existence AAB файла
- Проверить размер (должен быть ~10-50MB)
