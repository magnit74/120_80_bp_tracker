# Мониторинг сборки bundleRelease

## Контекст
Сборка `bundleRelease` запущена в ~15:41. Kotlin daemon активен. APK/AAB пока не появился.

## Задача
Каждые 2 минуты проверять статус сборки:
1. Проверять наличие APK/AAB в `android/app/build/outputs/`
2. Проверять, живы ли процессы Java (Gradle/Kotlin daemon)
3. Проверять最新ние логи ошибок
4. Сообщать пользователю: завершена/идёт/ошибка

## Проверка
- `Get-Process java` — живы ли процессы
- `Get-ChildItem android/app/build/outputs` — появились ли APK/AAB файлы
- Проверка log файлов на наличие ошибок
